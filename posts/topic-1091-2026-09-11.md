# 还在Excel里一根根抠图表？微软开源Flint，把数据丢给AI直接出图

先说结论，可能得罪人：运营周报、活动复盘、月度数据分析这类业务图表，还在 Excel 里一根一根柱子手动调的人，多半在浪费时间。

微软在 GitHub 上开源了一个叫 Flint 的东西，专门给 AI 用的数据可视化语言。我在小公司做运营，用了两三周，周报里的图表部分基本全交给它，现在开 Excel 主要是为了看原始数据。

做运营的都懂。

数据本身不难，难的是图。

拿我周一来说：上午导出数据，七八个指标，要出折线图、堆叠图、漏斗图。折线图还好，漏斗图是真恶心——早期 Excel 压根没有漏斗图，得用堆积条形图硬凑；新版本是有了，点出来还得调间距、配色、排序，一不留神漏斗是倒着的。十几下点选，一张图好几分钟，七八张下来一上午没了。

这还没完。抠完图老板来一句“这个再按区域拆一下”。重做。

先说清楚 Flint 是什么，免得误会。它不是一个做图的网站，也不是独立软件，而是一套可视化“语法”，你可以理解成 AI 跟图表之间签的一份合同。

以前你让 ChatGPT 帮你做图，什么下场？要么甩你一段 Python 代码让你自己跑，要么给你画一张“像手绘的”图，坐标轴歪的，标签挤成一坨。让 AI 直接写 Vega-Lite 或者 D3 也不行，语法太复杂，它一幻觉，给你一段看起来挺像样的代码，跑起来报错。

微软的思路就是造一门足够简单、约束足够严、关键词很少的语言，专门给 AI 写。你用大白话讲需求，AI 翻译成 Flint，Flint 再渲染成图。中间每一步都按固定规则来，AI 想乱来都没地方下手。

具体怎么上手。

GitHub 搜 microsoft flint，仓库开源，README 里有在线 Playground 的入口，点开就能贴数据试。我自己用得更多的姿势是配合 ChatGPT 或者 Claude：把数据和需求丢给 AI，让它写 Flint 代码，再把代码拿回去渲染。

一个提醒：Flint 比较新，模型可能不太熟。仓库里有语法说明，第一次用的时候把 README 里的语法介绍那段贴进对话，生成质量会好不少。别问我怎么知道的，它第一回给我编了一个根本不存在的语法。

我把自己磨出来的 Prompt 模板放这儿，直接复制改占位符：

```
你是数据可视化专家。以下是我的数据：
[粘贴你的数据，CSV 或直接贴表格都行]

请帮我生成符合以下要求的图表的 Flint 代码：
- 图表类型：[折线图 / 漏斗图 / 堆叠柱状图等]
- X 轴：[你的字段]，Y 轴：[你的字段]
- 分组维度：[你的字段，比如区域、渠道]
- 标题：[你的标题]，标题里要能看出核心结论
- 按 [某个字段] 降序排列

注意：先看懂我的数据结构，字段含义不明、日期或单位不清楚的，先问我，别猜。确认后只输出 Flint 代码，不要多余解释。
```

最后那句“先问我，别猜”是灵魂。加上之后，AI 瞎猜字段的毛病少了很多，之前它把我日期列当文本处理，给我画了张抽象画。

最爽的一次是上周的广告漏斗。曝光、点击、落地页访问、表单提交、成交，五段数据丢进去，一句“漏斗图，降序，每段标注转化率”，半分钟内搞定。换 Excel 是什么流程？点击、调格式、算转化率、一个个加文本框，没什么好比的。

折线图也是。周报里我说“近 12 周销售趋势，按区域一条线，表现最好的那个区域高亮”，这种小强调需求它真听懂了，头部那条线加粗变色。这效果在 Excel 里手动抠，又得十来分钟。

话说回来，我不是要把 Excel 一棒子打死。

临时看个趋势，两三个数据点，Excel 还是最快，没必要兴师动众。但有两类场景，Excel 是死路：一类是周报这种重复劳动，数据每周变，图表样式不变，用 AI 加 Flint，换一份数据，Prompt 原样照抄就行；另一类是带点“理解数据”的需求，比如“取前 10 名，剩下的合并为其他”，在 Excel 里你得先自己预处理数据，AI 一句话的事。

提效多少，我的真实体感：周报图表这块以前要抠一上午，现在午饭前能收尾。心态上变化更大——以前只肯做三张图，多做一张烦一次，现在愿意多试几个角度，反正改就是一句话的事。

不过有三盆冷水要泼，都是我拿教训换的。

一，AI 会看错数据。日期格式、单位混着来、“销售额（元）”这种带括号的列名，都是重灾区。生成的图看起来越像那么回事，越要抽查几个数。我被坑过一回，它把空单元格当成了 0，那周的流量下滑画得格外“真实”，差点让老板以为出了大事故。

二，数据合规。你是在把数据贴进 AI 工具，公司有规定就用内部批的，或者先脱敏：区域改成 A、B、C，金额乘个系数。做图是小事，数据捅出去才是真麻烦。

三，别指望它把你变成数据分析师。Flint 解决的是“画图”，不是“看懂”。图为什么掉、下一步怎么办，还是你的脑子的事。而且它画得越快，老板追问得也越快，你反而被逼着真的去看数了。这可能是它真正的副作用——没法糊弄了。

我现在分工挺明确：临时看数，Excel；周期性、批量的业务图表，AI 加 Flint；给客户看、对品牌规范要求严的，设计师。

我是「AI生产力空间」，每天一个 AI 技巧，工作效率翻倍。问一句：你做周报图表的时候，哪张图最让你头大？我猜被漏斗图折磨过的不止我一个，评论区聊聊。
