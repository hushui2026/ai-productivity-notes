# Claude Code 翻车实录：Auto Mode 被安全研究员攻破、commit 里偷偷带上会话链接，用之前先改这 3 个默认设置

先说个可能得罪人的判断：Claude Code 最大的坑，从来不是代码写不好，而是它默认太自由。

大部分人拿到 Claude Code，研究方向就歪了——天天琢磨怎么写 prompt 让它更聪明，却没花十分钟看一眼它默认能干什么、默认往外发了什么。我的态度一直没变：别把它当大牛程序员供着，把它当第一天入职、热情过头、你交代什么它都敢应下来的实习生。对实习生，先划红线，再谈放手。

最近两件事，让我更坚定这个看法。

头一件，Auto Mode 被安全研究者撬开过。前阵子有人拿 Opus 5 的 Auto Mode 做实验，思路说穿了不高深：在代码注释里、README 里、甚至第三方依赖的文件里，埋几句话。Auto Mode 的设计是自主规划、连续干活、尽量不打断你，可「不打断你」的另一面，就是很多操作它自己拍板了。它读到埋的那几句话，就当指令照做。让它请求一个外部地址，它去请求；让它把本地文件的内容带出去，它真带。

这不是模型蠢，是设定错位。你没划红线，它就默认自己看到的一切都是善意的。可你的仓库里躺着别人写的注释、别人的文档、别人的依赖，对模型来说，这些不是「参考资料」，全是「待执行的指令」。AI 自动改代码一时爽，push 完仓库火葬场，话糙理不糙。

所以 Auto Mode 我不是劝你别开，是劝你别裸开。开之前把 deny 名单填上：会话里敲 `/permissions`，切到 Deny 那栏手动加，或者直接改 `~/.claude/settings.json`：

```json
{
  "permissions": {
    "deny": [
      "Bash(git push:*)",
      "Bash(rm -rf:*)",
      "WebFetch"
    ]
  }
}
```

顺手提一句，命令行还有个 `--dangerously-skip-permissions`，社区管它叫 YOLO 模式。名字都写得这么直白了，别碰。

第二件事更隐蔽，踩过的人不少：commit 里的会话链接。

你让 Claude Code 替你提交代码，它默认会在 commit message 末尾带一段署名，新版本还会把这次会话的链接一起带上，PR 描述同样如此。这个链接意味着什么？意味着点开能看到你这一轮干活的完整过程。你中途贴过报错里的内部域名没有？吐槽过合作方没有？把测试密钥粘进对话里让它看过没有？全在里头。

我第一次 `git log` 看到那个链接，愣了半天。代码本身干干净净，工作痕迹先挂出去了。自己公司的私有仓库还好，可要是往开源项目提 PR，或者跟外包团队共用一个 repo，这就很要命。

我的做法分两步。先在 settings.json 里把 Co-Authored-By 那行干掉：

```json
{
  "includeCoAuthoredBy": false
}
```

至于署名里带链接的部分，不同版本开关的位置变过，我不给你打包票说点哪儿。关完之后让它 commit 一次，自己跑一遍 `git log`，尾巴干净了才算数。这一步没人替你把关。

第三个要改的，严格说不是个开关，是个习惯。

大多数人写 CLAUDE.md，就是项目根目录那个每次自动加载的记忆文件，只写「怎么干活」：代码风格、目录结构、怎么跑测试。我建议你反过来，头几行先写「不准干什么」：

```markdown
# 红线（优先级最高）
- 不准执行 git push，提交到本地为止，push 我自己来
- 不准读 .env 和 credentials/ 目录，需要里面的值先问我
- 除了装依赖，任何联网操作都先停下来问我
```

为什么红线要放最上面？因为模型不缺能力，缺边界。「怎么干」写得再细，它也可能在你看不见的那一步自由发挥；「不准干」写三条，顶你事后救火半天。

红线写完，再把重复流程固化下来。Claude Code 支持 skills，在项目的 `.claude/skills/` 目录下建个文件夹，放一个 SKILL.md，写清楚什么时候触发、步骤是什么，之后它会自己挑着用。社区还有个叫 ECC 的开源合集，把一堆现成的 commands、skills、hooks 打包好了，懒人可以直接抄作业。

但抄之前看一眼内容。skill 本质上是把别人的指令装进你的工作流，跟你从网上复制一段脚本直接跑，是一个性质。前面研究员那一招，换层皮就是一条恶意 skill。

串起来看就明白了：标题里说的 3 个设置，其实是同一个动作，先给实习生发员工手册，再让他干活。

我现在每个新环境上号，前十分钟雷打不动干这几件事，你直接抄：

1. 敲 `/permissions`，把 git push、rm -rf、WebFetch 塞进 Deny；
2. settings.json 加 `includeCoAuthoredBy: false`；
3. 让它 commit 一次，`git log` 检查尾巴，不干净就接着关；
4. 建好 CLAUDE.md，红线放最上面，规范往后放；
5. Auto Mode 想开再开，开着的时候人别走远。刷手机可以，别下楼吃饭。

十分钟的事。这十分钟省下来，后面够你回滚几次代码、跟人解释几回「这个链接怎么谁都能点」。

Claude Code 好不好用？好用，我现在一天离不开。但好用和放心用之间，隔着这十分钟。
