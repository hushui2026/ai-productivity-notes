# 拆同行视频，从一下午一条到一晚三条：用 Claude 把 B站/油管视频转成图文笔记

上周我在一个自媒体群里甩了张图：一个四十多分钟的 YouTube 教程，被我变成了一份带画面截图的中文笔记。全程没开播放器，用的就是 Claude。

群里做美食探店的老同学阿凯，当晚就来私聊我。这串聊天记录基本能回答所有人的疑问，征得他同意，整理出来。

阿凯：这是你自己边看边截的？

我：AI 干的。把视频链接丢给 Claude，它自己下载视频、抽取画面、把音频转文字，三样材料凑齐了再分析，最后输出图文笔记。B 站和油管的链接都能丢。

阿凯：等等，Claude 能看视频？我上次丢链接，它说访问不了。

我：网页版确实不行。我说的是 Claude Code 加一个插件，项目叫 claude-video，GitHub 上最近 star 涨得挺猛，就是专门补这块的。

阿凯：Claude Code 又是个啥。

我：Anthropic 自家的桌面工具，本来给程序员写代码用，现在开放了插件系统。装上 claude-video，它就多了“看视频”这一手。

阿凯：听着就很程序员。我一个拍视频的，装起来得多久？

我：Mac 上没你想的难。先装两个底层工具，打开终端敲一行：`brew install yt-dlp ffmpeg`。yt-dlp 管下载，ffmpeg 管抽帧转码。然后打开 Claude Code，照着 claude-video 的 README 敲插件安装命令，大概是 /plugin marketplace add 加 /plugin install 两步，以仓库最新说明为准。前后十几分钟的事。

阿凯：Windows 呢？

我：建议先进 WSL，就是 Windows 里套的那个 Linux。我在公司 Windows 机器上试过硬装，依赖报错报得我怀疑人生，切进 WSL 之后顺畅多了。别问我怎么知道的。

阿凯：装完要写代码吗？

我：不用，说人话就行。我最常用的开场是这么说的：

```
帮我把这个视频整理成图文笔记：[视频链接]
要求：
1. 输出完整口播文案，保留说话人的节奏和口语感，别润色成新闻稿
2. 每个内容段落配一帧对应的画面截图，标注出现的时间点
3. 结尾用 3 句话概括核心观点
```

阿凯：然后它就开始转圈？

我：对，你能看到它在下载、抽帧、转录，一步步来。半小时的视频，一杯咖啡没喝完就出结果了。提醒一句，视频越长越烧 token，两小时的纪录片我跑过一次，看完用量有点肉疼。建议长视频先让它出文字稿，挑出重点段落再细拆。

阿凯：这玩意儿对我有什么用？我拍探店的。

我：那你每周的固定节目可以改改了——拆同行。你以前怎么拆的？

阿凯：开 1.5 倍速逐帧看，边看边记备忘录，一条视频拆一下午。

我：换个问法：

```
这是一个同赛道博主的视频：[视频链接]
请站在内容创作者角度拆解：
1. 开头的钩子是什么，前 30 秒的信息密度够不够
2. 整条视频分几段，每段承担什么叙事功能
3. 口播文案里有哪些情绪词和高密度信息点
4. 画面节奏：镜头切换快慢，转场前后画面怎么呼应
5. 如果我拍同主题，最值得借鉴的三个点
```

阿凯当晚拆了三条同类爆款。第二天他跟我说了句话，我印象很深：原来我以前看视频，只看了个热闹。逐字稿摊开、关键帧摆在那，哪个转折在铺垫、哪个镜头在赶节奏，一眼就能看出来。

阿凯：那英文视频呢？我想学运镜，好教程全在 YouTube 上，还都是英文的。

我：这是我用得最狠的场景。英文视频直接丢，让它出中文笔记：

```
这是英文视频教程：[视频链接]
整理成中文学习笔记：
1. 按视频内容自然分段，每段一个中文小标题
2. 涉及操作的部分，命令和界面名称保留英文原文，解释全部用中文
3. 每个步骤配一帧对应画面，说明画面里在干什么
4. 专业术语第一次出现时，用大白话顺带解释
```

运镜这种东西，纯文字描述很抽象。但每一步都配着它从视频里抽出来的画面帧，照着比划就行。我那份 FFmpeg 教程笔记就是这么来的。

阿凯：听着太美好了。有坑没？

我：讲真，有几个。先说最要紧的：别拿去洗稿。拆解学习没问题，但画面和文案都有版权，搬去做二创，账号迟早出事。然后是兼容性，付费视频、会员专区的视频，yt-dlp 经常下不动，B 站某些内容还会拦。还有，Claude Code 得订阅才能用，Pro 起步，想白嫖的这条路暂时走不通。

阿凯：那 B 站 App 里自带的 AI 视频总结，不就够用了？

我：看你要什么。平台那个总结，就给你几行干巴巴的摘要，框架是它定的。claude-video 是把逐字稿、画面、结构全交到你手上，你想按什么维度拆就按什么维度拆。一个是帮你划重点，一个是把整本课本给你。对我来说差得挺多。

阿凯：行，我今晚就装。

我：卡住了随时喊我。
