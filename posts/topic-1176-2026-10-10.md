# Anthropic 给打工人发福利：Claude Cowork 知识工作插件库开源，写周报、做表格、理纪要直接抄作业

上周在 GitHub 闲逛，看到 Anthropic（做 Claude 那家）开源了一个仓库：knowledge-work-plugins。我第一反应是，得，又是个给程序员玩的东西。

点进 README 看了两眼，不是。这是一套 Claude 的插件，服务对象是「知识工作者」——说人话就是每天跟 Word、Excel、PPT、会议纪要泡在一起的人。运营、HR、销售、行政，全被点名了。

要知道 Claude 生态里之前的插件，十个有九个是代码补全、终端工具，跟普通打工人半毛钱关系没有。这次官方直接把办公室的活儿包圆了。我周末把仓库挨个跑了一遍，筛出 5 个最值得装的，外加一个藏得挺深的玩法，你直接抄。

丑话说在前面：这套插件不是网页版 Claude 里点两下就能用的，它需要一个「能动手干活的 Claude」。官方配套环境叫 Claude Cowork，Anthropic 新出的桌面工作台，用 Claude Code 也行，都要订阅。前提不满足，仓库再香也白搭。

好，开抄。

## 1. docx 插件：周报不用重写，让 Claude 直接改你的 Word

这条是最戳我的。

以前让 AI 帮忙改周报，流程是：从 Word 里复制出来，粘给 AI，AI 吐一段，我再粘回去调格式，一来一回半小时没了。

docx 插件干的事，是让 Claude 直接打开你电脑上的 .docx 文件，在文件里改。而且改动走 Word 的修订模式，它动了哪里全部标红，你逐条接受或者拒绝。它是打字的，拍板的还是你。

```
打开 [你的周报文件.docx]，用修订模式，根据 [你的本周进展.txt] 更新内容：
- 已完成的待办标记为"已完成"
- 新增事项按文档里现有格式补进去
- 语言风格跟原文保持一致，别加花活
```

改完打开文件，右侧一排修订记录等着你审。

## 2. xlsx 插件：脏表格丢给它，说人话就行

做运营的应该都见过那种表：日期格式五花八门，客户名前后带空格，还掺着重复行。

以前这种活得写公式甚至 VBA。现在直接说人话：

```
打开 [你的销售明细.xlsx]，把数据清洗一遍：
- 日期统一成 YYYY-MM-DD
- 删掉完全重复的行
- 客户名称前后的空格清干净
- 加一列"月度合计"，用 SUMIFS 按月汇总
```

重点是 SUMIFS 那行：它写进去的是真公式，不是把算好的数字贴上去。下个月数据一换，公式自己会更新。就冲这一点，市面上不少「AI 表格工具」比不了，那些给的往往是死数字。

## 3. zoom-transcript 插件：会议纪要，从录音到成稿一条龙

打工人最烦的活之一：会开完了，还得写纪要。

这个插件把整条链路接起来了。把会议的录音或录像文件丢给它，它先转全文，然后你再说一句按模板出纪要：

```
这是 [你的会议录音文件]，先转写全文，然后输出纪要：
- 结论放最前面，三句话以内
- 待办事项逐条列出负责人和截止时间
- 没吵出结果的争议点单独一节，别混进结论
```

我们组试下来，纪要基本是会还没散就躺群里了。以前这活默认归我，理由是「你打字快」。现在谁都不用打。

## 4. pptx 插件：出的是能编辑的 PPT，不是图片

AI 做 PPT 我踩过坑，号称一键生成，出来是拿图片糊的幻灯片，改个标题都得重跑一遍。别问我怎么知道的。

pptx 插件出来的是正经 PowerPoint 文件，文本框、图片都是独立元素，能拖能改字号。审美这事就别为难 Claude 了，平均水平。但「初稿它出、你来精修」这个分工，是真能跑通的。

## 5. scheduler 插件：约会议这种事，也轮不到人来干了

这条我本来没抱期望，结果回不去了。

它对接 Google Calendar 和 Outlook，你说一句：

```
下周约 [你的客户名] 做复盘会，30 分钟，
看我下周哪几个时段有空，优先排下午。
```

它真的会去读你的日历，把空档挑出来，还能顺手把会议邀请发出去。以前协调时间是来回问「您哪天方便」，现在让 AI 自己查日历。销售和行政应该最先受益。

## 6. 意外的一条：让 Claude 给你自己造一个插件

这条藏得深，我是在仓库文档的角落里翻到的。

官方插件装完之后，你其实可以让 Claude 照着它们的样子，做一个只属于你的插件。比如我把自己的周报模板固化成了一个插件，现在每周五说一句「该写周报了」，它自己知道去哪拉数据、按什么格式写、存进哪个文件夹。

操作不复杂，装好官方插件后直接说：

```
参考 docx 插件的结构，帮我做一个自定义插件，
功能是：[你想要的功能，比如每周五自动汇总指定文件夹里的文档，生成周报草稿]
```

插件的文件结构、说明文档它全给你生成好。不会一行代码也能做。

我觉得这才是这个仓库最狠的地方：Anthropic 把「插件」这个原本属于程序员的东西，做成了说句话就能量产的日用品。

如果你看完想今晚就试，路径我贴在这，照抄就行：

1. 确认有 Claude 付费订阅，装 Claude Cowork（官网可下）或 Claude Code
2. GitHub 搜 anthropics/knowledge-work-plugins，README 里每种装法都写了
3. 用 Claude Code 的话，两行命令完事：

```
/plugin marketplace add anthropics/knowledge-work-plugins
/plugin install docx@knowledge-work-plugins
```

（xlsx、pptx、scheduler 同理，把名字换掉就行；用 Cowork 的话，在设置的插件一栏把这个仓库地址添加进去）

4. 从 docx 开始练手，拿一份下周才交的周报试，别拿重要文件练
