# DeepSeek V4 Flash 跑分与价格横评：对比 GPT-4o-mini，办公和写代码怎么选 API 最省钱

上周有读者在后台问我：公司不让用网页版，想自己接 API 做长文总结和会议纪要，一个月得花多少钱。这个问题真没法一句话答，选错模型，账单能差出一个量级。正好 DeepSeek V4 Flash 刚发布，我花一个周末，把它和 GPT-4o-mini 放一起，跑分看了，价格算了，活儿也真干了。今天一次说清楚。

**跑分先放一边，我更信自己手里的活儿**

官方榜单我就不贴了，说个大概：V4 Flash 和 GPT-4o-mini 在综合测试上基本贴着走，代码相关的榜还略高一点，长链条的复杂推理则明显不如各家的大杯模型。但说实话，榜上差零点几分，跟实际用着顺不顺手，是两回事。

我拿三件事试的：一篇八千字的行业报告总结，一份带口误和错字的会议录音转写稿，一个三百来行的 Python 脚本改 bug。

体感是这样的。中文长文总结，V4 Flash 抓点比 4o-mini 准，4o-mini 的中文偶尔带点翻译腔，读完总觉得哪里“隔”了一下。会议纪要俩都能用，V4 Flash 更听话，你给格式它就照着来，不多喘一句。写代码，小函数、补测试、改小 bug 都顺手，但上下文一长它就开始丢细节，这种活儿我直接切大杯，不犹豫。

**账算下来，可能跟你猜的不一样**

先叠个甲：API 价格三个月一调，下面是我查价那天官网挂的数，你下单前自己再核一眼。

DeepSeek V4 Flash：输入五毛一百万 tokens，缓存命中一毛，输出两块，凌晨错峰时段再打对折。

GPT-4o-mini：输入 $0.15、输出 $0.60 每百万 tokens，折成人民币大概一块一、四块三上下。

通义那边的 flash 档还要更便宜些，新用户送免费额度，这篇先不展开。

按那位读者的用法算笔账：每天总结十篇长文，每篇输入一万 tokens、输出八百，一个月 V4 Flash 不到两块钱，4o-mini 四块多。对，你没看错，个人轻度使用就是几块钱的事，选哪个都不用心疼。

差别在量大的地方。独立开发者做批量处理，一天几千万 tokens 的流水，两个模型一个月能差出几百上千块，这才到需要纠结的量级。

但我折腾完发现，真正的大头根本不在选哪个模型。

**调用方式比选模型更省钱**

几个我亲测有效的招，按狠程度排。

最见效的是管住输出。输出比输入贵好几倍，V4 Flash 的输出是输入的四倍价，模型每句客套话都是你掏钱。我总结类的请求现在都挂这个模板：

```
你是我的办公助理。我贴给你一篇长文，只按下面格式输出，不要开场白，不要解释，不要"希望对你有帮助"：
1. 一句话结论，30 字以内
2. 三个关键点，每点不超过 20 字
3. 一件需要我跟进的事
以下是原文：
[你的长文]
```

就这一条，我的账单肉眼可见地瘦了。

缓存是第二招。把固定的指令、参考资料放在请求最前面，而且一字不改，重复调用就能命中缓存，输入费直接砍到五分之一。DeepSeek 开放平台后台的用量统计里能看到命中率，我的常驻任务现在能到七八成。OpenAI 那边是自动缓存，命中的部分输入打五折，不用你操心。

然后是错峰。DeepSeek 凌晨那几个小时半价，不着急的批量活儿，定时跑的摘要、打标签、数据清洗，挂夜里跑。别问我怎么知道半夜的任务最香。

砍上下文，这个很多新手不知道：API 跟网页聊天不一样，它没有记忆，每一轮请求都要把之前所有对话重新发一遍、重新计一遍费。所以五十页的 PDF 别整个塞进去，先让便宜模型出个摘要，拿摘要去问问题。一个聊了三十轮的会话，真不如开个新的。

再送一个：OpenAI 有 Batch API，批量任务半价，二十四小时内出结果。一次性处理上千条商品评论这种不着急的活儿，扔给它。
