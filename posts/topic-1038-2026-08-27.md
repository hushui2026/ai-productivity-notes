# 受够了AI写2000字废话？套用这3个Prompt技巧模板，逼GPT/Claude直接甩结论

最近 GitHub 上有个叫 i-have-adhd 的项目突然火了。其实它的核心就是一套特殊的 AI提示词，专门用来减少AI废话。说实话，我第一次看到这东西时心想，这不就是咱们打工人天天盼着的职场效率神器吗？

平时用 AI，你肯定遇到过这种崩溃时刻：让它查个资料，好家伙，先来两百字背景介绍，再分几个大点巴拉巴拉，最后还要给你来个“综上所述”。我只想知道结论啊！掌握点 Prompt技巧，强迫 AI 改掉这种八股文毛病，真的太有必要了。

上周我要写个竞品分析的周报，丢了一堆网页链接给 AI，让它总结核心动态。它洋洋洒洒给我吐了快两千字，把竞品的前世今生都给我科普了一遍。我盯着屏幕看了五分钟，硬是没找到那句“竞品这周主要降了价”的核心信息。有时候AI写的周报比我自己干的活还长，老板看了估计也得头疼。要是 AI 能直接甩结论，该多好。

这个爆火项目的逻辑很简单：它强制 AI 模拟一个注意力极度不集中的人来看文本。既然你注意力不集中，AI 就必须把结论放在第一句话，中间不能有任何铺垫，排版要大量留白，核心词要加粗。虽然这种做法有点极端，但思路完全正确。大模型训练时吃了太多公文和报告，它默认那套“起承转合”才是专业的。我们要做的，就是通过 Prompt 把它的这种惯性打回去。

为了看这个减少 AI 废话的提示词到底好不好使，我拿了一份 20 多页的行业研报，改写了一版中文的精简指令，分别丢给了 GPT-4o、Claude 3.5 Sonnet 和 Kimi 做对比。任务要求都是一样的：提炼研报里的三个核心趋势，禁止铺垫。

先看 GPT-4o。它的反应最快，几秒钟就把结果甩给了我。排版确实清爽了不少，没有再给我讲行业背景。但我发现 GPT-4o 在追求“不废话”的时候，容易用力过猛。它把一些本来挺关键的推导过程给砍了，直接抛出结论，导致我看的时候有点懵，不知道这个数据是怎么来的。我自己试下来，GPT-4o 像个为了赶下班直接把半成品甩你脸上的实习生，虽然快，但糙。如果你只是想快速查个资料，它够用；但涉及稍微复杂点分析时，它精简得有点没道理。

Claude 3.5 Sonnet 我个人更习惯用。讲真，我对 Claude 一直有偏爱。Claude 本来长文本处理就强，套上这套停止废话的指令后，表现最符合我的胃口。它不仅把结论提到了最前面，还能用极少的字数把逻辑链条串起来，不啰嗦但也不丢信息。比如在总结某个趋势时，它直接写“趋势一：成本上升，主因原材料涨价”，一句话把结论和原因讲透。Claude 就像个老成持重的大哥，你跟他说别说废话，他就真的能挑重点讲，还能顺带把逻辑闭环给你画好。如果你要做长报告阅读或者代码 Review，我强烈建议用 Claude。

Kimi 的情况有点特殊。Kimi 咱们国内访问快，平时也用得多。套上指令后，它的排版明显变好了，结论也突出了。但 Kimi 有个执念，它总觉得自己是个贴心的助理。我都明令禁止说客套话了，它偶尔还是会“皮一下”，在结尾忍不住加一句“希望这份总结对您有所帮助”。就像个刚毕业还带点学生气的助理，你交代的事情它干了，但总忍不住要在汇报完加个鞠躬。虽然不影响阅读，但总感觉它还是没完全摆脱“AI 客服”的影子。不过日常办公足够了，胜在网速快、免费额度足。

光知道对比还不够，这套思路得能直接落地。我结合平时的打工场景，把原版 ADHD 提示词拆解改写了一下，弄了三套可以直接复制用的模板。

写周报的时候，直接用这套，逼它说人话。

```markdown
你是一个资深职场人。请根据我提供的[你的本周工作流水账]生成一份周报。
必须严格遵守以下规则：
1. 第一句话必须是最核心的产出结论。
2. 禁止使用“本周我完成了”、“综上所述”等无意义的开头和结尾客套话。
3. 用要点形式列出，每点不超过20个字，只写动词+结果。
4. 删去所有形容词、副词和过度修饰。

我的流水账：[你的本周工作流水账]
```

遇到长文不想看，查资料的时候，直接扔这个过去。

```markdown
阅读以下[你的文本或文章链接]，并回答我的问题。
输出要求：
1. 第一段直接给出你的核心答案，不要有任何背景铺垫。
2. 如果有多个原因或步骤，请用极简的列表呈现，禁止解释基础概念。
3. 只提供能直接支撑结论的数据或事实，忽略所有无关背景。

问题：[你的问题]
文本：[你的文本或文章链接]
```

程序员高频的代码 Review，也可以这么搞。

```markdown
请 Review 以下代码。
严格规则：
1. 直接指出潜在 Bug 或可以优化的地方。如果没有致命问题，只回复“代码良好，无致命问题”。
2. 禁止解释代码逻辑，禁止教我基础语法。
3. 每个问题必须包含三要素：行号、问题描述、修改建议（直接给一段代码）。

代码：[你的代码]
```

要是你觉得每次复制粘贴这些模板太麻烦，可以直接把它们存进工具的系统设置里。比如用 Claude，现在有个叫 Claude Skills 的功能，你可以在左侧栏找到 Projects，新建一个项目，把这些规则写进 Custom Instructions 里。以后只要在这个项目下对话，AI 就会自动遵守这套规矩，不用每次都发一遍。ChatGPT 也有类似功能，点左下角头像 -> Custom Custom Instructions -> 把模板贴进去就行，全局生效。Kimi 的话，在对话框旁边的设置按钮里也能存类似的系统提示词。

说实话，用 AI 久了你会发现，最影响效率的不是 AI 不聪明，而是它太“话痨”。我们每天处理的信息量太大了，没有精力去废话里淘金。把控制权拿回来，强制它按咱们的阅读习惯输出，这才是 AI 真正能帮上忙的时刻。
