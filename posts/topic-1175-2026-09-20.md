# 腾讯开源 BrowserSkill 两周实测：每天导报表、查五十个订单、拉内部报销单，AI 用的就是你登录好的 Chrome

我最近有个越来越确定的判断：过去两年 AI 一直干不了活，卡的从来不是智商，是登录。腾讯把 BrowserSkill 开源放出来之后，我认真测了两周，更确定了。

你让 ChatGPT 帮你把昨天的销售数据从后台导出来，它能给你写八百字方法论，头头是道。然后呢？它进不去你的后台。账号在你浏览器里，密码在你脑子里，验证码在你手机上。AI 的能力边界，就是那个登录页。

所以各路补丁方案都来了：写爬虫的，拖 RPA 流程的，求 IT 开接口的，全都又贵又脆。BrowserSkill 走的是另一条路：它是腾讯开源的一个浏览器自动化技能，走 MCP 协议，配进 Claude Code、Codex 这类 AI Agent 之后，AI 能直接操作你正在用的那个 Chrome——注意，是「你正在用的、什么都登录好了」的那个，不是它自己弹出来的空白浏览器。

这句话信息量很大，我拆开讲。

**真正的墙，是登录态**

写过代码的都懂，让机器替你访问一个后台，最难的不是点按钮，是「证明你是你」。登录要 token，token 挂在 cookie 上，cookie 会过期；登录有滑块、验证码、短信；好不容易过了，还有风控盯着你。公司内部系统更绝，压根没有对外接口，你连爬的门都摸不着。

你的全部工作，其实都锁在一层登录态后面。AI 再聪明，隔着这层墙就只会聊天。

以前的解法我基本都试过。影刀、八爪鱼这类 RPA，拖流程确实不写代码，但后台一改版选择器就断流，维护起来比自己手动点还累。写 Python 爬虫就更别提，模拟登录、处理反爬，没个把月下不来。这些方案的问题不是不好用，是脆，页面稍微一变就废。

**装起来比我预想的顺**

去 GitHub 搜 Tencent/BrowserSkill，README 写得算清楚，命令直接抄，他们更新得勤，我就不贴具体命令了免得过时。流程两步：先 npm 装 CLI，跑一次初始化，它会问你配哪个客户端，我选的 Claude Code，MCP 配置它自己写进去；然后照 README 里的链接装配套的浏览器扩展。

装完进 Claude Code 敲个 /mcp，看到浏览器相关的工具上线，就成了。

我第一次装完死活没反应，捣鼓了十分钟发现是扩展压根没启用。别问我怎么知道的。

**三个被低估的点**

第一，登录态直接复用。我 Chrome 里登着电商后台、公司 OA、一堆 SaaS，AI 上来就能用，全程不碰我的密码，也不碰验证码。你根本不可能把带两步验证的账号安全地交给任何外部工具，但借浏览器用一下，这事就通了。

第二，不抢鼠标。我之前用过某类浏览器 Agent，屏幕上真有个光标在那儿替你点，你只能干看着，手一碰鼠标就断。BrowserSkill 在页面层面操作，我让它导报表，自己在旁边写文档，互不打扰。这个体验差距，用过才知道。

第三，出错它会自己看页面。有次后台弹了个「导出任务排队中」，按 RPA 的逻辑这就死在等待那步了。AI 是读懂了那行字，等了一下，自己跑去下载中心把文件捞出来。页面上它看得见字，改版、弹窗、按钮挪位置，它都还有机会自己应付。这是它跟传统自动化最本质的区别。

**三个我真实跑过的场景**

最日常的，导报表。prompt 直接抄：

```
打开生意参谋（浏览器里已登录），导出昨天的商品效果数据：
1. 进入「商品」→「商品效果」
2. 日期选昨天，指标保持默认
3. 点下载，等报表生成后保存到 [你的文件夹路径]
4. 文件名改成「昨日商品效果_今天的日期」
5. 完成后把文件路径告诉我
```

它选日期、点下载、等排队、去下载中心拿文件、改名、报路径，全程我一口没插。这事不难，烦的是每天雷打不动都得点一遍，现在这烦没了。

第二个，批量查询。同事甩来五十个订单号要查物流状态，以前要么一个个搜，要么写脚本，而写脚本得先逆向人家的查询接口，值不当。现在整串单号连要求一起丢给 Claude Code，它自己开页、查询、记录，最后汇总成一张表给我。

第三个，也是我觉得最狠的：操作公司内部系统。内网 OA、老 ERP，没有任何 API，外部 AI 之前完全没辙。但浏览器里我登着啊。我让它去内部审批系统，把我上个月名下的报销单状态全拉了一遍，汇总成表。IT 部门此前对此的答复是「做不了接口」。现在不用接口了。

**比一下，我态度明确**

专业开发要大规模稳定抓数据，正经爬虫和工程化 RPA 还有位置，我不抬杠。但如果你是运营、行政、电商卖家、市场，一年就几十件重复的网页破事，去学爬虫或影刀，投入产出比很差：学的时候痛苦，学完页面一改全白学。

自然语言把需求说清楚，AI 用你的浏览器去做，页面改版它自己认。门槛从「会写代码」降到了「会把话说清楚」。这种需求我以前都得求开发帮忙，现在说完它自己就跑起来了。

冷水也得泼。

它用你的真实登录态，意味着它能干的事等于你能干的事，包括删数据、改价格、发消息。这个权限级别自己要想清楚。我的做法：尽量用只读或小权限账号；删除、上架、打款这类按钮，让它执行前先停下来问我；新任务第一次跑，我盯着，不挂后台就跑。好在它是本地运行、开源可审计，不用把账号密码交给来路不明的 SaaS。但本地不等于零风险，权限始终是你的，不是它的。

测完这两周我有点感慨。大家老讨论 AI 会不会取代谁，但真正卡住普通人的，从来是这些登录框、验证码和内部系统。BrowserSkill 把最后一堵墙拆了个口子，而且是以普通人装得起、用得起的方式拆的。

你日常工作里，哪件事最想甩给 AI，却一直因为它「进不去系统」干瞪眼？评论区说说，我挑几个看看能不能拿 BrowserSkill 撸出方案。

我是「AI生产力空间」，每天一个 AI 技巧，工作效率翻倍。
