# 生成3000字却脑补85万销量？这3个防幻觉Prompt，让AI写报告不翻车

前几天四大会计师事务所之一的毕马威闹了个大笑话，因为用 AI 写报告导致严重事实错误，最后不得不公开撤回。这事在我们几个做企业咨询的群里炸了锅，大家都在转。

说实话，我看到新闻第一反应是后背发凉。因为就在上个月，我也差点在一份行业竞品分析报告里栽跟头。

事情是这样的。老板周五下午突然甩给我一个任务，让我下班前搞出一份《新能源汽车出海欧洲市场竞品分析》。这种活儿平时没个一两天根本啃不下来，资料浩如烟海。我当时心想，这不正好有 AI 嘛，直接把几十份研报喂进去让它提炼不就完了？

我一开始用的是最粗暴的办法：把一堆 PDF 扔给 ChatGPT，直接在对话框里敲“帮我总结这些研报，写一份新能源汽车出海欧洲的竞品分析报告，重点对比比亚迪、蔚来和吉利”。

结果它洋洋洒洒给我吐了三千字，排版工整，逻辑严密，看着特别像那么回事。

我当时都要准备发给老板了，多留了个心眼，扫了一眼里面的核心数据。结果发现它居然写“比亚迪2023年欧洲销量达到85万辆，蔚来海外营收同比增长120%”。我一看就觉得不对劲，去查了一下原始研报，好家伙，比亚迪压根没那个数据，那120%的营收增长更是AI纯粹脑补出来的。

我当时人都傻了。如果这封邮件发出去，周一早会我就得收拾包袱走人了。

后来我仔细琢磨，发现很多人对 AI 有个致命的误解。大家觉得只要 Prompt 写得好，AI 就无所不能。但讲真，AI 本质上就是一段代码，它的智商和知识边界是训练时就定死的。你无法通过几句提示词，就把一个本来就喜欢一本正经胡说八道的模型，瞬间变成严谨的行业专家。

单纯指望 Prompt 救不了笨 AI，但我们可以在 Prompt 里加上限制条件，强迫它别乱发挥。

那天下午我推翻了重写，换了个思路，死死卡住它的事实来源。最后硬是在下班前交了差，老板看完还挺满意，觉得我效率高。

复盘一下，我当时主要靠了三招防幻觉的提示词技巧，今天直接分享给大家，写报告或者做数据分析时一定能用上。

第一招，强制要求引用原文链接或原句。

很多人让 AI 写东西，习惯让它直接给结论。比如“总结这份财报的三大风险点”。它给你写出来的东西，看着挺专业，但全是大模型根据上下文概率编出来的漂亮话。正确的做法是，绝不让它直接给结论，而是逼着它做“带原文出处的填空题”。

我当时给它的指令是这样的：

```
你是一个严谨的行业分析师。请根据我提供的资料，撰写一份关于[新能源汽车出海欧洲市场]的竞品分析报告。
核心要求：报告中的每一个观点、每一个数据，都必须直接引用我提供的原文原句作为支撑。
如果原文中没有提及某项数据或观点，请直接回答“资料中未提及”，绝对不允许你自己补充或推断。
格式要求：在每段陈述后，用括号标注出处，如（来自《研报A》第3页：“原句原句原句”）。
```

这个方法特别管手。AI 只要有缝可钻就会脑补，你把路给它堵死，它就没法胡编乱造了。如果你用的是 Kimi 或者 Claude 这种能直接读取网页的工具，还可以把上面那句改成“必须附带原文的原文链接 URL”，它要是给不出真实链接，你一眼就能识破。

第二招，分步推导，拆解任务。

之前我图省事，一股脑把所有要求都抛给 AI。这就好比你让实习生同时去查五个公司的资料还要写万字长文，他最后只能瞎编。AI 也一样，任务太重，它为了迎合你，就会产生幻觉。我试过让它一次性写完，结果通篇废话，所以后来我改成了分步走。

我先让它只做一件事：提取数据。

```
请仔细阅读以下资料，不要做任何总结和评价。你的唯一任务是提取关于[比亚迪在欧洲的销量数据、车型定价、渠道布局]的事实信息。
将提取出来的内容整理成表格，只保留客观事实，删除所有形容词。
如果资料中没有提到定价，就在表格对应单元格里写“无数据”。
```

等它老老实实把表格列出来，确认数据没问题了，我再开第二个对话窗口，把表格丢给它，让它根据这个表格做对比分析。

把“找事实”和“写报告”拆开，等于给它加了张草稿纸。中间这个核对环节，就是我们的安全网。我发现分步走之后，不仅幻觉少了，写出来的东西逻辑反而更清晰，肉眼可见地顺手了。

第三招，逼 AI 评估自己的置信度。

这招有点反直觉，但效果出奇的好。咱们平时问 AI，它什么都说得信誓旦旦。其实你只要在 Prompt 里加一句话，它自己就会认怂。我在做最后的数据整合时，加了这么一个要求：

```
在报告生成后，请对你报告中陈述的每一个事实进行置信度评估（高/中/低）。
如果评估为“低”，请说明是因为资料不足还是数据存在冲突。
对于置信度为“低”的陈述，请在报告末尾单独列出，提醒我需要人工复核。
```

结果那天 AI 自己在报告末尾列了三句话，说这三处数据它其实是猜的，置信度低。我赶紧去查原始文件，果然是几份研报的数据打架了，它自己融合得不太对劲。如果没有这个让 AI 输出置信度的机制，这三处错误就被我直接复制粘贴发出去了。

说实话，这套流程走下来，确实比无脑扔给 AI 要慢一点，但比起你自己一行行翻原版研报，快了不止一倍。我自己试下来大概能省一半时间，关键是它保住了我的饭碗。

毕马威的事闹得这么大，其实就是给所有职场人敲了个警钟。AI 是个好用的拖拉机，但你不能松开方向盘。别迷信你的 Prompt 写得多牛，事实核查这关，永远得你自己过。
