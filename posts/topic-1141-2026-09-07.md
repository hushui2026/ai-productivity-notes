# 我用清华开源的 OpenMAIC 上了一节 SQL 课，被 AI 同学问得冒汗

先扔一个可能会挨骂的观点：**自学这件事，卡住你的从来不是缺资源，而是没有人向你提问。**

所以我看到清华把 OpenMAIC 开源出来的时候，第一反应不是「又多了个 AI 工具」，而是——囤网课这个动作，可以彻底停了。

不信你打开自己的收藏夹看看。SQL 三天速成、数据分析零基础入门、XX 框架从入门到精通……少说躺着上百个教程，真正看完的有几个？收藏那一刻的满足感，跟学会它几乎一样爽。这是人性，别不好意思，我也一样。

但今天我想说的不止「囤课没用」，而是一个更扎心的判断：

**单开一个 ChatGPT 对话框自学，和囤网课，是同一种病。**

## ChatGPT 是个好仆人，但不是好老师

你想想自己用 ChatGPT 学习的样子：问一句，答一大段，答得行云流水，还贴心地加粗重点。你从头读到尾，频频点头，感觉自己行了。

关掉窗口，让你自己写一遍，傻眼。

这在认知科学里有个说法，叫流畅性错觉：内容越顺滑，你越觉得自己掌握了。实际上你只是「看懂了别人懂的东西」，离「自己会」隔着一条鸿沟。

那真实课堂为什么有效？说实话，不全是因为老师讲得好。是因为课堂里有三样东西，AI 对话框里一样都没有：有人抢答，把你没想到的坑提前暴露出来；有人盯着你做题，错了当场逮住；还有随堂提问，你被迫当场组织语言。

你也试过跟 ChatGPT 说「考考我」吧？它出的题软绵绵的，你答错了它还安慰你「这是一个常见的误区，不用担心」。跟这种老师学，能学出什么危机感。

## OpenMAIC：一间全是 AI 的教研室

OpenMAIC 是清华团队（THUKEG，就是搞学堂在线那拨人）开源的多智能体教学系统，免费用，代码全公开。一句话讲清它是什么：它不是又一个聊天机器人，而是一间教室——讲师、助教、同学，全都是 AI。

拆开看这间教室里坐着谁。

**讲师 agent** 负责授课，但不是把文档糊你脸上，而是分段讲，讲到关键处停下来提问，看你的反应决定往下走还是再讲一遍。

**助教 agent** 负责答疑加巡逻。你卡住了它来引导，你答错了它顺着错误往下追。

**同学 agent** 是我觉得最妙的设计。一群模拟出来的同学，会提傻问题，会抢答，会从你没想过的角度插一嘴。

而这间教室的核心武器，是苏格拉底式提问——它不急着给答案，先反问你。「你觉得这两种写法查出来的结果一样吗？为什么？」你被逼着开口组织语言的那一刻，学习才真正开始。

## 我上了一节 SQL 课，被 AI 同学问得冒汗

上个月我动了学 SQL 的念头。运营出身，取数老求人，别问我怎么知道这种痛。正好拿 OpenMAIC 试，让它开一节数据分析 SQL 的课。

开课先交代底子，我大概是这样写的：

```
我想学 [你想学的东西，比如：SQL 多表查询]。
我的基础：[零基础 / 会一点 / 能看懂但写不出来]。
我的目标：[比如：两周后能独立取数做周报]。
每天能学：[大概多久]。
节奏宁慢勿快，每个知识点讲完先考我，再往下走。
```

课讲到 WHERE 和 HAVING 的区别。讲师停下来提问，我字还没打，「同学」先抢答了一个错的。讲师没直接纠正，反问全班：那聚合函数的执行，在 WHERE 之前还是之后？然后点名我。

我愣住了。这两个关键字我照猫画虎用过很多次，从来没想过执行顺序这回事。支支吾吾答了一半，助教跳出来，顺着我的错误又追了两个问题，一直问到我把整个执行流程自己捋顺为止。

讲真，这种感觉，单开 ChatGPT 一年也体验不到。因为 ChatGPT 的默认人设是服务你，你说啥它顺着啥；而这间教室里几个 agent 的任务设定是「教会你」，它们有自己的教学目标和节奏，你跑偏了会被拽回来。

顺带说，这个模式对好几类人都对口。运营、市场学 SQL 和数据分析，最典型，不缺速成收藏，缺的是有人逼着真写两句查询；程序员啃新框架，让讲师按你的基础开课，AI 同学问出来的问题，往往就是你以后 code review 会被问的；考证考研的，把它当一群随叫随到的研友加答疑学长；练英语口语则是被低估的场景——一堆 AI 同学陪你讨论，脸皮再薄也有地方开口了。

## 免费开源，上手不难，丑话说前面

GitHub 搜 OpenMAIC，仓库全开源。上手路径：克隆下来，按 README 配好你自己的大模型 API Key，跑它的一键启动命令。具体命令别照抄我这篇，以仓库 README 为准，那玩意更新得比我公众号勤快。

丑话也得说在前面，免得你回头骂我：本地跑要折腾一点环境，纯小白可能在装依赖那步就开始怀疑人生；API Key 走自己的账单，好几个 agent 同时说话，token 烧得比普通聊天快不少，上长课心里要有数；同学 agent 偶尔戏太多，插嘴插得你想让它闭嘴，好在配置里都能调。

还有一句实话：它替代不了真正的好老师和真同学。它替代的，是你自学时那种没人管的裸奔状态。

## 收藏夹怎么办

我的态度很明确：从今天起，收藏夹里的教程，要么三天内打开，要么删掉，别留着骗自己。真想学会点什么，就开一间 OpenMAIC 的教室，让那几个 AI 讲师、助教、同学盯着你。

被提问的滋味确实不好受。但学习这件事，本来就不该是舒舒服服刷完一节又一节视频。
