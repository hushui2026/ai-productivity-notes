# 别再海投了！我用 Claude Code 搭了个全自动求职框架，3天搞定定制简历+面试题库

先说个可能得罪人的观点：海投简历，是求职里最隐蔽的一种偷懒。

听着刺耳，我先讲个事。去年有个朋友找我改简历，她投了小一百份，拿到面试的就俩。我问都投了什么岗位，她发来一张表：运营、产品、市场，甚至还有个“总经理助理”——用的同一份简历。

我说这不叫求职，这叫抽奖。

问题出在哪，拆开看不复杂。一个岗位挂出去，HR 收几百份简历，每份停留的时间以秒计，很多公司还先过机器筛选，你简历里的关键词跟 JD 对不上，可能连被人看见的机会都没有。而海投的人手里只有一份通用简历，通用，就意味着对哪个岗位都不够匹配。关键词对不上，重点对不上，人家凭什么捞你？

这个道理不新鲜，谁都懂。真正的问题是：定制太贵了。认认真真针对一个岗位改简历、写求职信、准备面试题，一套下来一两个小时，投十个岗位一天就没了。于是大家退回海投——点一下“立即投递”，心理上还能获得一种“我今天很努力”的满足感。

死结就在这：有用的活太贵，便宜的活没用。

上个月，我把这个结剪开了。用的是 Claude Code 加一个 GitHub 上的开源项目 `ai-job-search`，花了三个晚上把整套东西跑通。现在看中一个岗位，从把 JD 粘进去，到拿到一份改好的简历、一封求职信、一套模拟面试题，一集电视剧的功夫。

先给没用过 Claude Code 的朋友补两句。它不是网页版那个聊天框，是装在你电脑上、能直接读写本地文件的 Claude。这一点对求职特别关键——简历就是个文件，改简历本质上是改文件。网页聊天只能给你贴一段文字，Claude Code 是真把活儿干了。

那个 `ai-job-search` 项目，你可以理解成一套现成的求职流水线说明书。作者把“怎么拆解 JD、按什么标准评估匹配度、简历每个模块怎么改”全写成了规范，Claude Code 照着规范干活。你要做的，是把家底喂给它。

第一次搭建是一次性的。去 GitHub 搜 ai-job-search，点右上角 Fork，把它复制一份变成你自己的项目，再 Clone 到本地。项目里有个放个人信息的文件，照着格式把教育背景、每段工作经历、做过的项目、会的技能全部填进去。这一步别糊弄，填得越细，后面它改简历时能用的素材就越多。我让我朋友把“给公众号写过几十篇推文”这种细节都翻出来了。

填完之后，在终端里进入这个文件夹，敲 claude 回车，就能用大白话跟它对话了。

之后的每个岗位，都是同一套动作。

先把 JD 原文丢给它做匹配度评估。我常用的指令长这样，可以直接抄：

```
这是我的背景信息（项目文件里有）。下面是目标岗位的 JD：

[粘贴 JD 原文]

请做匹配度分析：
1. 逐条对照 JD 的硬性要求和加分项，给出匹配 / 部分匹配 / 不匹配的判断
2. 给出一个 0-100 的匹配度总分
3. 指出我背景里最能打动这个岗位招聘方的三个亮点
4. 诚实告诉我哪些短板没法包装，这个岗位我到底该不该投
```

第四条是我自己加的。别让 AI 只顺着你夸，让它先帮你劝退一批不靠谱的岗位，比多改五十份简历都省时间。

评估完觉得值得投，接着让它动简历：

```
基于刚才的匹配分析，修改我的简历：
1. 把和这个 JD 最相关的经历提到最前面，重新安排每段经历的详略
2. 在不造假的前提下，用 JD 里的关键词重写职责描述
3. 缺量化数据的地方，用 [需补充：具体数字] 标出来提醒我，不许编
4. 输出修改前后的对照，告诉我你动了哪些地方
```

第三条划重点。AI 有时候会顺手给你编一个“增长数据”出来，显得业绩特别好看，别问我怎么知道的。改完的简历务必自己逐行过一遍，哪句话过火、哪段经历被夸大，这个判断只能你自己做。简历里吹出去的牛，面试是要本人圆回来的。

再往下就是求职信和面试题。求职信让它基于匹配分析写，不用多教。真正被低估的是面试题这块：让它站在招聘方视角，针对这份 JD 和你的简历出一套“如果我是面试官我会问什么”，附回答思路。它问出来的东西经常很尖锐，比如“你简历里这段经历和你投的方向明显不一致，怎么解释”——这种问题，自己闭门准备的时候八成想不到。

说到这，估计有人要问：不懂技术，能搞定吗？

说实话，门槛比你想象的低，全程不用写一行代码。装 Claude Code 是官网下载、双击安装的事，命令行党一句 npm install -g @anthropic-ai/claude-code 也能解决，之后全是自然语言对话。你需要会的东西就两样：复制粘贴，以及把文件里的占位文字换成自己的内容。硬性门槛只有一个——得有能正常用 Claude 的账号，Pro 订阅就够，这块自己想办法。

回头看，这套东西改变的到底是什么？它没让找工作变简单，它把成本结构改了。以前定制一份简历要一小时，现在一集电视剧的时间，“每个岗位都认真定制”从不可能变成了日常操作。海投逻辑的地基——定制太贵、所以只能广撒网——被整个抽掉了。

所以我的判断很简单：还在海投的人，不是不努力，是把努力花在了回报率最低的动作上。工具是现成的，项目是开源的，缺的只是你花一个晚上把它跑起来。
