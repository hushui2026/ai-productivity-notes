# GPTBot、ClaudeBot天天来白嫖文章？这款字体让AI爬虫只能抓走乱码

上周四晚上十一点多，一个做独立博客的朋友突然甩来一条微信：“你睡了吗？我怀疑我的博客被 AI 爬虫盯上了。”

他写了三年的技术博客，服务器日志里天天有 GPTBot、ClaudeBot 这类 AI 爬虫的访问记录，文章就这么被抓走喂模型了。他问我怎么防 AI 抓取，聊着聊着就聊到了今天的主角——Ghost Font，一款“人类专属”的隐形字体。

那晚断断续续聊了一个多小时。对话我原样贴出来，删了点脏话。他简称 M。

M：你先看，我日志里 GPTBot、ClaudeBot，还有个 CCBot，三天来了几百次。它们在干嘛？

我：抓你的文章，回去喂模型。GPTBot 是 OpenAI 的，ClaudeBot 是 Anthropic 的，CCBot 属于 Common Crawl——很多模型的数据池就是从 Common Crawl 里舀的。

M：我写过同意书吗？

我：没有。目前这个阶段，公开发布的内容基本就是“默认可抓”。

M：那我 robots.txt 里全拉黑不就完了？

我：可以，语法也简单：

```
User-agent: GPTBot
Disallow: /

User-agent: ClaudeBot
Disallow: /

User-agent: CCBot
Disallow: /
```

但你要想清楚：robots.txt 是君子协定。大厂爬虫一般守规矩，可你拦不住别人把你文章复制走再转手。采集站、聚合站一倒手，源头是谁的早就说不清了。

M：所以防不住？

我：正面防不住，可以侧面恶心它。这就轮到 Ghost Font 出场了。

M：听着像玄学。

我：原理不玄，就一个字：换。

你肉眼看到的是"a"，文件里存的根本不是"a"。Ghost Font 靠的是同形字替换——把一部分拉丁字母，换成西里尔字母里长得一模一样的“双胞胎”。俄语的 а 和英文的 a，肉眼根本分不出来，但底层编码是两个完全不同的字符。

人看渲染出来的字形，一切正常。

爬虫复制原始文本，拿到手的是一堆“外语”，切碎喂给模型就是乱码。

M：等等，那人为什么还能正常读？

我：字体本质上就是一张“编码到字形”的对照表。Ghost Font 把这些替换进来的字符，字形画成正常字母的样子。你眼睛读的是画，爬虫读的是码，两边各看各的，互不打扰。

M：有点意思。怎么装？

我：看你的内容放在哪。

你是博客，走网站方案。GitHub 上搜 Ghost Font 进项目页，Releases 里下字体包，里面有 woff2 文件。扔进网站的 fonts 文件夹，CSS 里加一段：

```css
@font-face {
  font-family: 'GhostFont';
  src: url('/fonts/ghost.woff2') format('woff2');
}

.ghost-protected {
  font-family: 'GhostFont', serif;
}
```

正文那个容器挂上 ghost-protected 这个 class，完事。

装完怎么验证？打开你自己的网页，Ctrl+A 全选、复制，粘到记事本里。贴出来是乱码，成了；还是原文，说明字体没挂上。

M：Word 文档呢？我有些方案文档要外发。

我：包里也有 ttf 文件。Windows 上右键选“为所有用户安装”，Mac 双击，在字体册里点装。然后 Word 里选中文字，字体下拉切过去就行。

但有个坑你记一下：对方电脑没装这个字体，打开就是满屏豆腐块。别问我怎么知道的，我有次发文档出去，对面回我一句“这是摩斯密码吗”。

所以外发文档一律导成 PDF 再发。文件 → 导出 → 创建 PDF，Word 会把字体嵌进 PDF 里，谁打开都是你看到的样子。

M：那简历是不是也能这么搞？我的简历挂在网上好几年了。

我：简历千万别。

现在大半公司过简历靠 ATS 系统，机器先把简历解析成结构化数据，关键词对不上直接刷掉。你上了隐形字体，ATS 读出来"Python"变成了西里尔拼写，HR 看到的是一排问号。

你以为防了 AI，其实防的是自己的面试。

M：哈哈。那 SEO 呢？我博客一半流量是 Google 来的。

我：问到点子上了，这是它最大的代价。

Google 爬虫读的也是原始字符。换上隐形字体之后，搜索引擎索引到的同样是乱码，等于亲手掐断自己的搜索流量。

所以我是分页面用：教程页、引流页保持正常字体；熬夜写的深度长文、不想白送的核心内容，挂 ghost-protected。鱼和熊掌各分一半。

M：还有别的坑吗？

我：两个，都得知道。

一是无障碍。读屏软件读的也是底层编码，视障用户用读屏打开你的页面，听到的是火星文。你网站要是有无障碍合规要求，慎用。

二是防不住截图。现在多模态模型看图识字很猛，别人把你的网页整页截屏丢给 AI，照样啃得动。Ghost Font 封的是“复制文本”这条路，不是铜墙铁壁。

M：合着也没那么神。

我：本来就是篱笆，不是城墙。挡顺手牵羊的，挡不住铁了心的。

不过爬虫抓取是流水线作业，最讲性价比。它发现你这站抓回去全是乱码，清洗数据的时候大概率整批丢弃，不值得为你的几千字单独养一套 OCR。够用了。

M：行，我今晚就改。对了，公众号文章能用吗？

我：用不了。公众号编辑器粘贴的时候会把格式洗一遍，正文字体平台说了算，你插不进自定义字体。

M：那不等于没防。

我：所以才劝你去搭个博客啊。

那晚聊到十二点半，他去改 CSS 了。

第二天一早他甩来一句：“已上线，肉眼无差别。CCBot 还在来，这回抓走的全是乱码。”

隔着屏幕都能感觉到他解气。我倒觉得，这事的意义不在于真防住了谁——在于你终于对自己的内容说了算一次，哪怕只有一点点。
