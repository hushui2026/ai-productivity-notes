# 排班从拖一下午到只挪2格：GPT-5.6解题Prompt里，值钱的是框架不是话术

前几天刷到个挺炸的消息：有人用 GPT-5.6 配一段超长 Prompt，把一个挂了三十年的数学难题往前推了一大步。具体推到了哪一步，数学圈自己还在吵，但不影响全网狂欢——那段提示词当天就被存成各种版本的文档，我朋友圈起码五个人转发，配文清一色的“先马后看”。

我也认认真真把那段 Prompt 拆了一遍。今天这篇 Prompt 技巧，先给一个得罪人的结论：

**你抄了也没用。**

不是我清高。是那段提示词里压根不存在“神级话术”这种东西，没有一个字是魔法。它做对的事情只有一件：把一个模糊的大问题，拆成了一个模型能一口一口咬下去的框架。

而大多数人用 AI 干活翻车，死因恰恰在这。不是 Prompt 不够玄，是从头到尾没把任务说清楚。

它做的第一件事，是先定义“什么叫做完”。

那段 Prompt 开头不是“请解决这个问题”，而是先把终点画出来：最终交付物长什么样、边界划在哪、什么情况算越界。这个动作看着平平无奇，其实是一切的地基。

你回想一下自己平时怎么下指令的。“帮我排个班”、“帮我把这堆数据理一理”。这种话扔给一个真人同事，人家都得先反问你三个问题：几个人？什么规矩？啥时候要？AI 不会反问，它直接猜，然后交给你一份看着挺工整、实际没法用的东西，你还纳闷这 AI 怎么这么笨。

不是它笨。是你没说。

第二件事更关键：把大问题切成一条链。

那段 Prompt 的主体结构，就是逼着模型一步步推导，每一步只处理一个小问题，上一步的输出是下一步的输入。思维链这个词你可能都听烂了，但它的功力不在“分步”，在“切得干净”——每步的输入是什么、输出是什么，写得死死的。

对应到你的工作里，就是别让 AI 一口气算完。排班表不是一个任务，是五个任务：先列约束，再排初稿，再查冲突，再调平衡，最后出表。让它一步一步来，每步只干一件事，出了错你才知道错在哪一步。

第三件事，也是最被低估的一件：把验收标准提前写进去。

那段 Prompt 里有相当大的篇幅在定义“什么算对、什么算错、推完了怎么自查”。相当于把审稿人的活，提前塞进了任务书里。

这个普通人抄起来最实惠。与其等 AI 交完卷你再人工挑错，不如一开始就告诉它怎么算合格。它自己查一遍，比你肉眼扫三遍都管用。

框架说完了。我把它揉成一份职场能直接套的模板，排班排期、复杂的数据核算、梳理业务流程，都能往里塞：

```
你是一个[你的领域，如：排班调度]方面的资深专家，请帮我完成下面的任务。

任务目标：[把"做完"说清楚，如：输出下周一至周日共7天的值班表，5名员工，每天3个班次，表格形式]

已知条件：
[把约束全部列出来，如：A周末不能值班；B每周最多值5天；夜班必须配至少1名老员工；每人每周至少休息2天]

请严格按以下步骤推导，每一步先给结论，再说明理由：
1. 把所有条件整理成清单，标注哪些是硬性约束（违反即失败）、哪些是软性偏好（尽量满足）
2. 基于硬性约束生成初版方案，明确指出哪些软性偏好暂时没满足
3. 逐条自查初版方案有没有违反硬性约束
4. 对没满足的部分给出调整方案，并说明调整的代价
5. 输出最终方案，附一份简短的自查报告

如果条件之间互相打架，不要硬编一个结果，先把冲突点列出来问我。
```

最后那句是我自己加的，也是整个模板的灵魂。AI 最大的毛病，就是宁可编一个错的，也不肯承认你给的条件本身就有矛盾。把“可以反问我”写进指令，能拦住一大半翻车。

上周我拿这个模板干了票实事。给一个十几人的小组排月度值班，7条硬规矩，中间还夹着几条领导口头交代的软偏好。以前这种活在 Excel 里得拖一下午，改一个格子崩一串。这回前后聊了七八轮，中间 AI 反问我两次“这条规矩跟那条冲突了，你保哪个”，我拍板，它接着跑。最后出来的表，我只手动挪了两格。

那一刻我对“神级 Prompt”彻底祛魅了。

数据核算也是同一个道理。你把核算口径写成硬性约束、把“谁来复核、查哪些勾稽关系”写进自查环节，模型跑出来的东西，才敢往上报。

所以我的态度摆在这：收藏夹里那些《最强Prompt指令100条》，删了吧。你收藏的每一条“神级提示词”，本质上都是别人替他自己的任务把话说清楚了。换到你的场景，句子照搬，就是废纸。

真正该随身带的是三个问题：

这个事干完之后，终点长什么样？

中间能切成哪几步，每一步的输入和输出分别是什么？

好坏怎么判断，谁说了算？

这三个问题你答得上来，Prompt 随便写都不会太差。答不上来，抄一百条模板也救不了你。AI 再聪明，也没法替你决定“这件事到底要什么”，这一步偷懒，后面全是返工。

你最近一次让 AI 干复杂活翻车，是栽在哪一步？没说清目标，还是没给判断标准？评论区聊聊，我看看大家的死法一不一样。

我是「AI生产力空间」，每天一个 AI 技巧，工作效率翻倍。
