# 一年几万的舆情SaaS我没买：用Agent-Reach+Claude，0成本监控小红书/Reddit

我们公司不大，运营就三个人，但老板每个月都要一份「竞品舆情报告」。小红书上用户怎么骂竞品、Reddit 上老外聊了什么、YouTube 评论区是什么风向，全都要。

之前这活是我干的。每周固定抽一个下午，开十几个标签页，一个平台一个平台搜关键词，看到相关的就复制进飞书文档。一多半时间花在翻页和筛广告软文上，真正分析的时间不到半小时。

后来我实在受不了，把能找到的路子基本摸了一遍。今天就横评三种方案：纯手动、商业舆情工具、开源自建。结论先不剧透，反正我最后没花一分钱。

## 方案一：纯手动，最土，但不是不能活

先给手动党留点面子。如果需求就是「偶尔查一次、盯一个词、看看大概风向」，手动完全够用，还免费。

我的习惯是小红书站内搜然后按最新排序；Reddit 用 Google 搜 site:reddit.com 加关键词，比站内搜索好用得多；YouTube 直接搜完按上传时间过滤。

问题是这玩法撑不起「持续监控」。第一，没法定时，全靠自觉。第二，趋势看不出来，上周多少条、这周多少条，手动根本数不过来。第三，小红书搜索给你看的和实际存在的，讲真，不一定是一回事。

手动方案适合一次性、轻量级的抽查。超过这个量级，就是拿命换钱。

## 方案二：商业舆情工具，贵得有道理，但不是给你的道理

我也去问了报价。找了两家做舆情监控的 SaaS，销售都很热情，远程演示给你看仪表盘、情感曲线、负面预警推送，看起来确实专业。

报价下来我沉默了。入门档一年几千，想要小红书数据全一点、监测关键词多一点，一年几万很正常。而且这类工具的重心普遍在微博和微信公众号，小红书的覆盖深度要单独加钱，Reddit、YouTube 这种海外平台，好几家干脆没有。

钱是一方面，更大的问题是黑盒。它的情绪怎么算的、数据抓全没有，你不知道，也没法验证。我拿一条自己刷到过的负面吐槽去测其中一家的演示版，那条发了一周的帖子压根没出现在报告里。

商业工具适合有预算、要给管理层交正规报告、需要合规背书的中大型公司。小公司上这个，属于用高射炮打蚊子，还是租的高射炮。

## 方案三：开源自建，Agent-Reach + last30days-skill

主角来了。我现在在用的组合，成本为零，代价是要求你不怕命令行。

Agent-Reach 是个开源的 CLI 工具，思路很直接：给 AI Agent 提供一个统一入口，去扫描 Reddit、YouTube、小红书这些平台上的公开内容。last30days-skill 则是 Claude 的一个技能包，装上之后 Claude 能专门搜「最近30天」的新鲜内容，而不是甩给你一堆两年前的老帖子。

先说 Agent-Reach 怎么弄。电脑上有 Python 的话，几行命令的事：

```
pip install agent-reach
agent-reach --register
agent-reach --connect reddit
```

注册完、连上平台，就可以让它去扫了。比如我想看最近七天 Reddit 上提到某个竞品的帖子：

```
agent-reach --scan reddit --query "[你的竞品名]" --recent 7
```

跑完直接吐出帖子标题、链接、热度，格式规整，方便下一步喂给 AI。它支持的平台不止 Reddit，YouTube、小红书都在列表里。这里多说一句：参数我写的是自己机器上能跑通的版本，这工具更新挺勤，你装的时候如果对不上，直接看 GitHub 上的 README，别死磕我这篇文章。

last30days-skill 更省事。去 GitHub 搜这个名字，仓库 clone 下来，放进 Claude Code 的技能目录（一般在 ~/.claude/skills/ 下面），然后就能用大白话使唤它：「搜一下最近30天关于 [你的品牌名] 的讨论，重点看 Reddit 和 YouTube」。它自己去聚合最近的网页和帖子，再由 Claude 给你汇总。

## 光抓回来没用，得让 AI 干分析的活

数据只是原料。我真正觉得「调研费省下来了」的时刻，是把抓取结果丢给 Claude，配上这么一段提示词：

```
你是一个竞品舆情分析师。下面是过去7天从多个平台抓取的公开帖子数据。

请输出一份结构化报告，包含：
1. 热度变化：哪些平台、哪些话题的讨论明显变多
2. 情绪分析：正面、负面、中性的用户原话各摘3条，保留原文
3. 竞品动向：[你的竞品名] 有哪些新动作被用户提到
4. 风险预警：任何有发酵迹象的负面信号，标注来源链接
5. 行动建议：给运营团队的3条可执行建议，别写空话

原始数据：
[粘贴抓取结果]
```

然后我用 crontab 把抓取和总结设成每周一早上自动跑。周一到公司打开电脑，一份现成的 Markdown 报告躺在那儿，老板还以为我周末加班了。

我没有。

## 横评结论，看你的情况

三种方案没有碾压关系，看需求。

一个月就查一两次、只盯一个词，老老实实手动，别折腾。要持续监控、关键词多、想定时自动出报告还不花钱——Agent-Reach 加 Claude 这套，我认为是小团队的最优解，last30days-skill 当查漏补缺，特别是想快速看一眼「最近有没有新动静」的时候它最顺手。公司有预算、要交正规报告、在乎合规，商业工具该买还是买，毕竟人家有客服兜底。

我个人的主力配置是 Agent-Reach 定时抓加 Claude 总结，last30days-skill 随手查。要我自己掏钱买商业工具？不可能。

坑也得提前讲。小红书这类平台没有开放这种用途的官方接口，这些工具走的都是非官方路子，哪天突然抽风要有心理预期。抓取频率别设太狠，我一开始十分钟跑一次，风控差点没把我送走，别问我怎么知道的。另外抓回来的数据自己内部看看就行，直接拿去商用发布是有合规风险的。

这套折腾完，那个每周雷打不动的「搜帖子下午」就消失了，省出来的时间够我把报告再写细一点。
