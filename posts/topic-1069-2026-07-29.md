# 老板周五甩来200页行业报告？用Kimi K3做长文本处理和跨文档分析，省了一大半时间

这两天科技圈都在刷 Kimi-K3 的技术报告，各种技术名词满天飞。但我估摸着大家跟我一样，根本不关心它底层架构怎么改的，注意力机制怎么优化的，只关心一件事：这玩意儿到底能不能帮我干活？

前两天周五临下班，老板甩给我一个压缩包，里面是一份将近 200 页的医疗器械行业报告，外加七八个上市公司的财报，让我周一早上交一份行业洞察。当时我心就凉了半截。

以前遇到这种长文本处理，我试过拿 ChatGPT 切块喂，把 PDF 拆成十几个小段分别上传，前后问了十几次，结果上下文全断了，它根本串不起来前后的逻辑。也试过 Claude，虽然阅读理解强，但几十万字的 PDF 直接报错传不上去，文件大小卡得死死的。

既然 Kimi K3 发布了，长文本处理能力据说又上了一层楼，我就拿这个生死任务实测了一把。讲真，整个过程折腾了一晚上，但结果真的让我省了一大半时间，周一早上顺利交差。这里复盘一下我具体怎么操作的。

第一步是啃主报告。这份行业报告大概快 20 万字，我直接把 PDF 拖进 Kimi 网页版的对话框。以前用别的工具传大文件经常卡死或者直接白屏，Kimi 这边解析速度还行，等了几分钟，进度条走完，它自动把文档目录列出来了。

这里我踩了个坑。一开始我直接问“帮我总结这份报告”，结果它吐出来的东西像目录大纲，全是“本文分为五个部分，第一部分介绍了背景”这种废话。后来我改了问法，逼着它输出具体数据，效果好得多。

```
你是一个资深的行业分析师。请阅读我上传的[医疗器械行业报告]，提取出以下核心信息：
1. 市场规模与增长率：列出近三年的具体数据，并预测未来三年的趋势。
2. 竞争格局：市场份额排名前五的公司及占比。
3. 核心技术壁垒：用大白话解释目前该行业卡脖子的技术是什么。
请用 Markdown 表格呈现前两项数据，不要输出无关的客套话。
```

按这个 Prompt 丢进去，它老老实实去原文里扒数据，连脚注里的小数字都没放过。而且因为有超长上下文，它不会像以前那样总结到后半段就忘了前面的内容。我随机抽查了几个数据跟原文件比对，准确率很高，基本不用我再翻原文件去查了。这一步要是手工干，光是把这 200 页读完就得一整天。

光有主报告不够，老板还要我比对几家竞品公司的财务数据。这次我把 5 份不同格式的文件（3 个 PDF、2 个 Word，里面还掺着表格）一次性全选拖进了聊天框。

之前我用别的 AI 工具处理多文档，基本就是“东拼西凑”，每次只能针对一个文件问，然后再自己手动把结果汇总到 Excel 里比对。Kimi K3 在这方面的表现确实有点意思，它能在一轮对话里同时引用好几个文件里的数据做对比。

我用的 Prompt 是这样的：

```
请对比分析我上传的 5 份竞品公司财报，找出它们在[研发投入]和[营销费用]上的差异。
要求：
1. 分别列出每家公司的具体金额和占总营收的比例。
2. 找出研发投入占比最高和最低的公司，并给出原文中的解释说明。
3. 指出这几份财报中数据口径不一致的地方（比如有的用了“销售费用”，有的用了“营销及推广费用”），并统一口径后重新排序。
```

这招特别管用。它不仅把表格拉出来了，还真的指出了不同公司财报里名词不统一的问题。以前我自己肉眼看这几个文档，光是统一名词就得搞半天，现在直接让它帮我对齐，肉眼可见地顺手了。不过有一点要注意，它在输出表格时偶尔会把某一列错位，需要自己复制到 Excel 里稍微调一下格式，但这比起从零开始整理已经省了太多事。

数据扒完了，还得给老板看。老板那个人没耐心看长篇大论，我得把那几万字的分析重写成一份 800 字左右的简报。

正常情况下，我们跟 AI 对话，问个两三轮它可能就“失忆”了，或者开始胡编乱造。但我基于前面那份 20 万字的报告，一直连续追问。

我先让它写了一个 500 字的摘要。然后我觉得里面有一段关于“集采政策影响”的分析写得不够透彻，就接着追问：

```
针对你上面输出的第 3 点“集采政策影响”，请结合原报告中的“第四章 政策环境分析”，重新扩写这部分内容。
要求：
1. 扩充到 800 字左右。
2. 语气要客观中立，多用数据支撑，少用形容词。
3. 重点突出集采对中小企业利润空间的挤压效应。
```

它没有像以前我用别的 AI 那样，一旦追问就开始偏离原文瞎编，而是真的跑回那 20 万字的原文深处，把第四章的内容重新拽出来改写。这个超长记忆能力，确实不是吹的。最后我把改写好的几段拼起来，稍微润色了一下，直接发给了老板。老板还以为我周末熬了个通宵。

这么一通折腾下来，Kimi K3 在超长文本上的确有点东西，尤其是跨文档比对和持续追问不跑偏，这两点对经常跟长文档打交道的打工人太友好了。

不过它也不是完美的。比如有时候回复太长会突然卡顿一下，需要刷新网页，再比如输出的 Markdown 表格在微信排版里会乱，得自己转成图片再发。
