# 0 行代码、3 步搞定：我用 Dify 给部门搭了个文档问答机器人

上周我在朋友圈提了一嘴，说自己用 Dify 搭了个 AI 应用——给部门做文档问答的小机器人，一行代码没写。

做运营的老同学小林当晚就私聊我，连环轰炸了十几个问题。征得他同意，我把聊天记录删掉寒暄，只留干货整理出来。想入门 Dify 的，看完这篇基本能自己跑起来。

**小林：Dify 到底是个啥？跟直接用 ChatGPT 有啥区别？**

我：打个比方，ChatGPT 是别人造好的车，你只能开；Dify 是个组装车间。你在上面接各种大模型，GPT、Claude、DeepSeek、通义千问都行，再配上你自己的资料、提示词、流程，攒出一个只属于你的 AI 应用。

最直观的例子：把公司产品手册喂给它，它就变成一个只懂你们产品的客服，问啥都从手册里找答案，不会瞎编。

**小林：听着就得写代码吧？我纯文科生。**

我：不用。整个界面就是拖拽加点选，会打字、会点鼠标就够了。

唯一能碰到代码的地方，是工作流里有个「代码执行」节点，那是给程序员加餐用的，咱们可以一辈子不碰。

**小林：从哪开始？**

我：搜 Dify 官网，进它的云服务版 cloud.dify.ai，邮箱注册登录。

网上不少教程上来就教你 Docker 自部署，那是程序员玩的开源方案，图的是数据捏在自己手里。咱们先别碰，云版最省事。免费版有额度限制，个人玩、小范围用是够的。

**小林：进去之后点哪？**

我：首页点「创建空白应用」，会弹出几个类型：聊天助手、Agent、工作流、文本生成。

你先只管「聊天助手」，这是最简单的形态，一个带你自己设定和知识库的对话机器人。工作流后面再说。

**小林：模型怎么接？**

我：应用编排页右上角选模型，第一次它会引导你去设置里填 API Key，就是你选的那家模型的钥匙。去对应平台注册、生成 Key、贴进来，搞定。

我自己的搭配是 DeepSeek 干日常的活，便宜、响应快；要写正经文案的时候切 Claude。新账号有些模型自带一点体验额度，先白嫖着把流程跑通，再考虑充值。

**小林：那搭个啥练手？**

我：就搭你们部门的文档问答机器人，回报最快。下面这段是全文重点，拿小本子记。

三步走。

第一步，传资料。回首页，左侧栏点「知识库」，创建，把 PDF、Word、txt 拖进去。中途会让你选分段和索引方式，别纠结，全用默认，一路下一步，等它处理完。

第二步，回到应用，在编排区找到「上下文」，把刚建的知识库挂上。挂上之后，AI 回答会先去你的文档里翻，翻不到才靠它自己发挥。

第三步，写系统提示词。我常用的模板直接抄走：

```
你是 [公司或团队名] 的内部助手。
- 只回答和 [你的业务范围，比如产品功能、报销流程、请假制度] 相关的问题
- 回答必须依据知识库资料，资料里没有就回复「这个问题需要转人工」，禁止编造
- 用中文，简明扼要，涉及流程时分条列出
```

三步做完，右边预览框直接测。问一个只有你文档里才有答案的问题，答对了就成了。

**小林：能跑，但它说话太啰嗦。**

我：提示词里加一条「回答不超过 80 字」。再去模型参数里把 Temperature 调低，这个值越低它越老实。客服场景我就调得挺低，写创意文案的时候才敢调高。

**小林：那「工作流」呢？看着很唬人。**

我：聊天助手是一问一答。工作流是让你画一张流程图，AI 照着图干活。

比如「客户留言进来 → 自动判断售前还是售后 → 售前查产品库回答，售后查工单流程回答」。这种带判断、带分岔的活，聊天助手干不了，就得上工作流。

编辑界面是块白板，左边一堆节点，开始、LLM、知识检索、条件分支……往中间拖，连上线，试运行。上手没你想的难，但建议先把聊天助手玩熟，搞懂知识库和提示词是怎么回事再来看，不然容易懵。

顺便说 Agent：那是让模型自己决定调不调工具，适合搜索、查数据这类。新手阶段先跳过。

**小林：搭完怎么给别人用？总不能让人登我账号。**

我：应用右上角点「发布」，会生成一个公开链接，发给谁都行。

旁边还有「嵌入到网站」，能生成一段代码贴进你们自己的网页，变成右下角的悬浮客服。要走 API 接进公司系统也行，那个让你们开发去弄。

对了，每次改完编排记得重新点「发布」，不点的话别人看到的还是旧版。这个坑我踩过，改了半天以为没生效，差点摔鼠标。

**小林：还有什么坑，提前给我交个底？**

我：两个。

知识库不是传完就高枕无忧。文档的切分质量和原始格式，直接决定问答效果。表格多的 Excel 别指望它答准，先把内容整理成干净的段落文字再传，效果天差地别，别问我怎么知道的。

另一个，别把 Dify 当万能神。链条长的工作流偶尔会抽风，中间一个节点判断错，后面全歪。重要业务一定留人工兜底。

**小林：行，周末我就去试试。**

我：先只搭查资料的机器人，跑通了再想别的。一上来就想搭自动化流水线的，基本都卡在半路。
