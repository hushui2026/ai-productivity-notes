# 2小时录像几分钟出纪要：claude-video 自动提取字幕与画面要点

很多人以为让 AI 看视频是个极高门槛的技术活，或者觉得大模型只能处理文字，遇到视频就只能干瞪眼。别逗了，现在都什么年代了。如果你还在用2倍速硬看几个小时的培训录像，或者为了找一个会议回放里的某句话把进度条拖来拖去，我劝你赶紧停。其实让 AI 帮你做视频摘要，把视频转文字再提取要点，才是真正能省下大把时间的正解。最近我用一个叫 claude-video 的开源工具跑通了 AI 看视频的流程，讲真，体验完全是降维打击。

Claude 官方网页版本身不支持你直接扔个 mp4 文件进去，这大概是很多人觉得它干不了这活的原因。遇到长视频，大部分人的常规操作还是老老实实坐着看，顶多开个2倍速。但你要知道，视频本质上就是连续的图像加上一条音轨。既然大模型能看图能读字，为什么不能把视频拆成它能消化的格式？

这个叫 claude-video 的开源工具，干的就是这个拆解的脏活累活。它的底层逻辑其实挺粗暴的，但非常管用。

它先在后台把你的视频下载下来，然后把音轨分离出来去做视频转文字，生成完整的字幕。光有字幕还不够，有些教程视频画面里的操作步骤是没语音对应的。所以它还会按照一定频率对视频抽帧，比如每隔几秒截一张图。最后，把这些截图和字幕文本打包在一起，一股脑扔给 Claude 去分析。

这等于是给大模型配了一双能抓重点的眼睛和一对顺风耳。

这工具的安装稍微需要点动手能力，但绝对没你想的那么复杂。前提是你电脑得有 Python 环境。打开终端，把项目克隆到本地，进入目录，敲一行命令安装依赖包。因为你得调用 Claude 的能力，所以还需要去 Anthropic 官网弄一个 API Key，填到工具的配置文件里。如果你需要处理 B站或者 YouTube 的链接，还得装一个叫 yt-dlp 的命令行下载工具。这步环境配置对纯小白可能有点劝退，但装好之后就是一劳永逸的事了。这步搞不定的话可以去搜一下 yt-dlp 的安装教程，环境依赖的坑挺多的，别问我怎么知道的。

等环境跑通后，你只需要输入一个简单的 `/watch` 命令加上视频链接，剩下的事情就是去泡杯咖啡。工具会在后台疯狂运转，下载、抽帧、转录、调用 API。你在终端里能看到它不断跳出处理进度，几分钟后，一份结构化的总结就直接甩在你面前了。
